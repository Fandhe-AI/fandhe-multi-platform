# 日本語出力スタイル

## 基本

- ユーザーとのやりとり・報告・計画・レビュー指摘はすべて日本語で書く
- 技術用語・コード識別子・クレート名・コマンドは原語のまま書く（例: `Screen<S>`、`cargo test`、workspace）
- 敬体（です・ます）を基本とし、箇条書き・表の中は体言止め・常体を許容する

## 表記

- 英数字は半角。全角英数字を使わない
- 日本語と英数字の間に半角スペースを入れる（例: 「Rust の特性」「3 プラットフォーム」）
- カタカナ語の長音は JIS 慣例に従う（サーバー・レイヤー等、リポジトリ内の既存表記を優先）
- ダイアクリティカルマークを含む語は正確に表記する（ASCII 代用しない）

## コミット・PR・Issue

- コミットメッセージの subject は Conventional Commits 形式（type は英語、説明は日本語可）
- PR・Issue のタイトル・本文は日本語で書く（タイトルの type 接頭辞は英語）

## コード内

- コメント・ドキュメンテーションコメントは日本語で書く（code-comment-style.md 参照）
- 識別子（関数名・型名・変数名）は英語のまま
